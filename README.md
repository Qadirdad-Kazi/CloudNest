# CloudDrive

A modern, secure cloud storage platform built with React and TypeScript.

## Features

- 🔐 Secure file storage and sharing
- 👥 Role-based access control
- 📁 Intuitive file management
- 🌙 Dark mode support
- 📊 Admin dashboard
- 📱 Responsive design

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Lucide Icons
- Vite

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/clouddrive.git
cd clouddrive
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

### Demo Users

- Admin: admin@cloudrive.com
- User: user@cloudrive.com
- Guest: guest@cloudrive.com

Password for all accounts: `password`
