# AR-Web Stable Frame Capture System: Step-by-Step Testing Guide

## Prerequisites
1. Ensure the server is running (`npm run dev` in the server directory)
2. Ensure the client is running (`npm run dev` in the client directory)
3. Make sure you have a webcam connected to your computer
4. Have a physical object ready for scanning (preferably something with distinct features)

## Testing Steps

### 1. Basic Navigation and UI Testing
- Open the application in your browser (typically http://localhost:5173)
- Navigate to the LiveScanner page
- Verify that the UI loads correctly with:
  * Camera view
  * Scan quality selector
  * Camera selector (if multiple cameras are available)
  * Start/Stop scanning button
  * Instructions panel

### 2. Camera Initialization
- Allow camera access when prompted
- Verify that the camera feed appears in the preview
- Test camera selector if you have multiple cameras
- Verify that changing cameras works correctly

### 3. Scan Quality Settings
- Change the scan quality setting between Low, Medium, and High
- Verify that the UI updates to reflect your selection
- Note any changes in frame rate or processing speed

### 4. Frame Capture Process
- Position your test object in the camera view
- Click "Start Scanning"
- Verify that:
  * The scanning process begins
  * Frame capture indicators show activity
  * The stability indicator responds to camera movement
  * Frames are being captured at regular intervals (every 300-500ms)

### 5. Object Detection
- While scanning, move the object slightly to different positions
- Verify that:
  * Object detection feedback appears on screen
  * Confidence scores are displayed
  * Bounding boxes appear around detected objects (if implemented)

### 6. Stability Detection
- Test the stability detection by:
  * Holding the camera very still and observing the stability indicator
  * Moving the camera slightly and observing changes
  * Moving the camera rapidly and observing the system's response
- Verify that the system continues capturing frames despite minor movements

### 7. Error Handling
- Test error scenarios:
  * Cover the camera lens briefly to simulate poor lighting
  * Move the camera very rapidly to test motion blur handling
  * Move the object out of frame to test object detection recovery
- Verify appropriate error messages or recovery behavior

### 8. 3D Model Generation
- Complete a full scan cycle (capture at least 20-30 frames)
- Click "Finish Scanning"
- Verify that:
  * The system indicates it's processing the frames
  * Progress indicators show the stitching process
  * A 3D model is eventually generated and displayed

### 9. Model Viewing
- Once the 3D model is generated, test:
  * Rotation controls
  * Zoom functionality
  * Different viewing angles
  * Model details panel

### 10. End-to-End Flow
- Perform a complete end-to-end test:
  * Start a new scan
  * Capture frames from multiple angles of the object
  * Complete the scan
  * Generate the 3D model
  * View and interact with the resulting model
  * Verify the model appears in the dashboard/gallery

## Performance Testing
- Note the time taken for:
  * Camera initialization
  * Frame processing
  * 3D model generation
  * UI responsiveness during scanning

## Browser Compatibility
- Test the application in different browsers:
  * Chrome
  * Firefox
  * Safari
  * Edge (if available)

## Issues to Watch For
- Camera freezing during scanning
- Delays in frame processing
- Failed object detection
- Poor quality 3D models
- UI elements not updating correctly
- Error messages not being displayed properly

Record any issues encountered during testing, including steps to reproduce, expected behavior, and actual behavior.
